Image Adjustments

Jul 16, 20263 min read

Image Adjustments are the alterations to a source image that modify it before it enters the lithophane generation pipeline. The appearance of the adjusted source image is what the pipeline will try to replicate in the finished, backlit lithophane. A source image is adjusted in two ways: its framing and its grading. The frame specifies what portion of the image is used, how it is oriented, and what size it will be when printed. The grade is the set of tonal and color transformations applied to the frame.

Adjusting a source image is purely about how the finished product should look. This is distinct from Preprocessing, where the image may instead be modified to suit the lithophane generation process itself, or to make the printed result more amenable to printing.

Adjustments are non-destructive

Image adjustments do not modify the source image file. Each setting is stored as a parameter. The browser renders a live preview by approximating those parameters with display-side filters, so the preview is only an approximation of the adjusted image the pipeline will actually act on. The framed and graded raster is reconstructed from the original source image only when a solve or export runs. This keeps any quirk of browser rendering from affecting the lithophane itself.

The frame

Beyond selecting which portion of the source image is used, the frame fixes how pixels on screen relate to the lithophane as a physical object. The frame’s dimensions are the dimensions of the printed lithophane. A lithophane should not be rescaled in a slicer: scaling the model alters the layer thicknesses, and it is those thicknesses that produce the image, so a rescaled print no longer reproduces it.

The frame’s dimensions, together with the solve pitch — the physical spacing between the points the pipeline solves for — also fix the print-scale raster: the version of the image the pipeline actually operates on, and the one shown in the preview. Working at print scale keeps the pipeline from solving for detail finer than the printer can render. That raster can look slightly blocky, but the blockiness is an honest depiction of how the image will resolve once printed.

The grade

The grade is a fixed-order chain over the sRGB raster:

  1. Grayscale, if black-and-white mode is selected, applied first so every later operation acts on a luminance image.
  2. Exposure, contrast, and saturation, as multiplicative gains of the form 1 + v for v ∈ [−1, 1]. Contrast pivots about the image’s mean gray level; saturation interpolates between the image and its grayscale.
  3. Tint, a recolor toward a chosen hue that preserves each pixel’s luminance. The target hue is rescaled so its luminance (Rec. 709 weights) matches the pixel’s, then blended in by the tint strength. The effect shifts chroma without altering brightness, and is skipped in black-and-white mode.
  4. Highlights and shadows, additive offsets gated by a luminance ramp. Highlights act only above mid-gray and shadows only below, each ramping to full strength at the extreme — at most ±80 levels on the 0–255 scale. This is a masked offset, not a tone curve.
  5. Temperature, an opposing per-channel shift: warm raises red and lowers blue, cool the reverse, by up to ±30 levels.

The result is clamped to eight bits per channel. This graded raster is the image the rest of the pipeline receives, beginning with Preprocessing and then The Solve.
