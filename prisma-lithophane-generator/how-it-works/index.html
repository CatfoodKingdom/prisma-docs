How It Works

Oct 07, 20264 min read

Introduction

This section explains what Prisma Generator does internally and why. You do not need these details to make a lithophane, but a rough mental model can help you use the Generator intentionally and understand why different images, palettes, and settings produce different results.

Believe your lying eyes

When you perceive an image on a screen or on a printed page, a small set of components creates the appearance of many colors. Monitors use red, green, and blue (RGB) as additive primaries. Many printers use cyan, magenta, yellow, and black (CMYK) as subtractive primaries. Neither approach reproduces every color found in the real world, and there is no single correct way to build every image from a limited set of color components.

3D printers are not normal printers

Many color-lithophane systems begin with a fixed CMYK-like filament set. Prisma instead lets the palette follow the colors in the source image and uses a calibrated color model to predict how the selected filaments appear when stacked and backlit. White remains a special material for the base, fill, and cap.

In typical color printing, the range of colors is achieved by changing the size and density of colored dots. Color lithophanes are closer to stacks of stained glass: every part of the image must be filled with plastic, and each material can change only at printed-layer boundaries. The active Extrusion Width and its minimum printable line length constrain the smallest reliable features. These limits reduce both the reachable colors and the detail the print can carry.

The complicated nature of the Prisma Generator’s pipeline and its many settings is an attempt to answer the question: “How can I reproduce any image in a color lithophane as accurately as possible given the many limitations of 3D printers?”

The pipeline

The pipeline used by Prisma Generator is my answer to that question. Instead of using CMYK, the filaments used are selected based on the colors actually found in an image. Then that image is processed in a series of stages to convert its pixels into regions of color that are actually printable.

The diagram below depicts the stages that convert an image into printable model objects and their material assignments.

The main flow runs left to right; the palette, color model, and lookup table feed the solve from below. When swaps are needed, a scout solve plans their bands before the final lookup table and solve. Select any stage to read how it works.

The stages

  • Image Adjustments — the framing and color grading you apply to the source photo in the first tab, before the automatic pipeline begins.
  • Preprocessing — an optional, configurable clean-up pass that conditions the image toward what the chosen palette can actually reproduce.
  • Target Colors — translating every pixel into a perceptual color space and onto the set of colors the palette can physically reach.
  • The Solve — the core step: choosing a filament recipe for each region of the image so the backlit result matches the targets while staying printable.
  • White Cap — converting the solved colors into a thickness map and adding a white layer that sets overall brightness.
  • Export — turning the finished layers into an STL or 3MF model the slicer can open.

Feeding the solve from the side:

  • Palette — the filaments chosen for a print, and how Prisma can suggest them from the image.
  • Color Model — the model that predicts how stacks of filaments will appear to your eye when backlit.
  • The Color LUT — a precomputed table of printable stacks and their predicted colors, which lets the solver compare recipes without calculating each stack from scratch.
  • Runs with Swaps — planning flat filament bands before the final solve when the palette contains more colors than the printer can hold at once.

How settings affect the process

The pipeline pages linked above describe this process from stage to stage. Settings: How They Work describes the same process through the current Settings drawer groups: Essentials, Preprocessing, Color Solver, and White Cap.
