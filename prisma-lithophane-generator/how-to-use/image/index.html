Image

Jul 28, 20264 min read

The Image tab is step 1: pick the photo, decide how big the print will be, and frame the part of the picture you want. Everything else in the app works from what you set here.

The whole Image tab with an image selected: Library and Preview on the left, the Adjustments panel with the framing canvas on the right.

Library

The Library pane holds your source photos. Each thumbnail shows the file’s name, pixel dimensions, and size; click one to select it (or drag it onto the framing canvas). Add Image can add one or several photos from your computer; the refresh button re-reads the folder; the expand button enlarges the pane when you have many images.

Switching to a different photo resets the framing — crop, scale, and rotation start fresh for the new image.

Prisma accepts JPEG (.jpg, .jpeg, .jpe, .jfif), PNG, TIFF, BMP, WebP, HEIC/HEIF (.heic, .heif, .hif), and AVIF. HEIC, HEIF, and AVIF photos may briefly show Preparing… before they appear. Prisma makes a disposable, color-normalized PNG for its own work; it does not change or replace the original.

The library is the Generator/Images folder beside Prisma’s executable. Add Image copies photos there, and you can also place files there directly and press refresh. Successfully prepared files appear automatically. If only some files in a batch can be read, the others still appear and a warning lists each failure with a suggested action.

Loading a saved run does not copy its archived photo into this folder. Prisma first checks whether a Library item has exactly the same source bytes, preferring the original filename when it matches. If there is no exact match, the archived photo becomes a temporary active image marked Saved run source. It can still be framed, previewed, used for palette suggestions, and solved, but it is intentionally absent from the Library thumbnails and count. Selecting any Library photo replaces that temporary selection; Prisma does not promote a saved-run source into the Library automatically.

Downloaded schema-version-1 runs that are loaded through Load from file… receive the conservative treatment for HEIC, HEIF, HIF, and AVIF sources: because that older archive shape contains the prepared PNG but not the original phone-photo bytes, Prisma keeps the source private instead of trusting editable archive metadata to select a Library photo. Native JPEG, PNG, TIFF, BMP, and WebP archive members can still be matched directly from their own bytes.

Clear Temp Files removes temporary saved-run sources. If one is active, Prisma also clears that selection and the solve/export history that depended on the cleared run cache. The saved archive is not deleted, so loading it again restores the source. Visible loaded-* files created by older Prisma versions remain ordinary Library files and are never altered automatically.

Prisma uses the primary still image and honors its orientation and common sRGB, Display-P3, BT.709, and SDR BT.2020 color information. Animated HEIF/AVIF and HDR-only PQ/HLG images are not supported; export those as an SDR sRGB JPEG or PNG first. RAW/DNG, videos, Live Photo video companions, GIF, JPEG 2000, JPEG XL, and MPO are also outside the supported image library.

Almost any supported photo can be solved, but that does not mean every photo will make an equally good lithophane. A sharp source with readable contrast and important details large enough to survive the print resolution is a stronger starting point.

Preview

The Preview pane shows the framed and adjusted target image that the rest of the app will use, with the physical dimensions marked. It is not yet a prediction of the printed result. If something important is cut off here, fix the framing before moving on.

Adjustments

The Adjustments panel on the right is where you set the print’s size and shape and, optionally, tune the picture itself. It has two sub-tabs:

  • Size — orientation, aspect ratio, physical width and height, crop framing, rotation, and an optional raised border.
  • Image — brightness, contrast, color adjustments, and a black-and-white mode.

Both are covered control by control in Adjustments. Reset (top right of the panel) returns everything to defaults.

The info bar

Under the controls, three figures summarize the setup:

  • Image Size — the source photo’s pixels.
  • Print Size — the physical size the lithophane will be.
  • Rendered Size — how many solve points the print works out to at the current resolution. This is the real detail level of the print: if it’s much smaller than the image size, fine detail in the photo won’t survive, no matter how sharp the source is.
