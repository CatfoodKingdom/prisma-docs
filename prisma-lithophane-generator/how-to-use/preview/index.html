Preview

Jul 15, 20264 min read

The Preview tab is where lithophanes actually get built and judged. You start a solve, Prisma works out the filament stack for every point, and the results land here for inspection — before you’ve spent any plastic.

A lot happens under the hood during a solve; you don’t need any of it to use the app. If you’re curious, How It Works explains the whole machine.

Starting a solve

Press Solve in the top bar. It needs two things: a selected image and an active palette in the Palette Deck — it stays grayed out until both exist. Progress shows while the solve runs, typically a minute or two depending on size and settings; you can cancel and keep using the app.

Preview cards

A finished solve appears as columns in the main area — your source photo beside the solved result. The bar above switches what the result shows: the predicted appearance, the white cap, the color regions, and more. Each view is described in Preview Card Modes; the extra diagnostic views behind the Advanced button are in Advanced Modes. Source Image: On/Off hides the source column when you want more room. Click any image to enlarge it.

One thing to know up front: the result can look blocky compared with the photo. That view shows the solve grid honestly rather than inventing image detail between solved points. A field-derived white-cap export may reconstruct a smoother physical cap surface, but it does not create new color decisions beyond the solve resolution.

Solve History

Every solve becomes a card in the Solve History column on the right, newest on top. Each card shows the run’s name, its palette colors, and RMSE %, the run’s overall color-error score. Lower is closer to the target, but use the predicted image rather than the number alone when choosing between runs. Details unfolds the settings the run used.

Click a card to show or hide that run in the main area. Showing two or more runs puts them side by side — the easiest way to judge whether a settings or palette change actually helped.

📸 Screenshot to capture

Two Solve History cards selected, with both runs displayed side by side next to the source.

To keep a run deliberately, save it. Clear removes the cards from the current Solve History display only. It does not delete automatic saves, cached run data, or explicitly saved runs; automatic saves remain available through Load.

Saving and loading solves

Press Save on a card and give it a name to keep that run permanently — result, settings, palette, everything.

Load (top of Solve History) opens the Saved Runs window: your saved runs plus recent automatic saves (each solve is quietly auto-saved, so a good result is usually recoverable even if you forgot to save). Select one to Load it back — it behaves exactly like a run you just solved, including being exportable. Save keeps an automatic save permanently, Rename and Delete manage the list, Download hands you the run as a file, and Load from file… brings a downloaded run back in — handy as a backup or to move a run to another computer.

When the result isn’t right

Compare the predicted view against the source and trust your eye. Colors falling short usually mean the palette can’t reach them — try another suggestion, more colors, or easing the photo’s saturation (see Adjustments). Missing fine detail usually traces to solve resolution or the white cap’s detail depth (see Settings). Change one thing, solve again, and compare the two runs side by side.
