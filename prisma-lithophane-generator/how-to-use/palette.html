Palette

Jul 26, 20265 min read

The Palette tab is where you choose the colored filaments available to the solve. Palette choice has a large effect on the result: Prisma can mix the colors you provide by stacking them, but it cannot make every target equally well from every set of filaments.

The white used for the base and cap is selected separately under Settings → Essentials. It appears on palette cards for context but is not one of the palette’s color filaments.

Both creation modes use the enabled Active Filaments from the currently active model library. If a filament is missing, check Configuration first; use Model Library → Manage in the left panel only when you mean to switch the complete published model library.

Auto-Suggest

Auto-Suggest tests combinations from the filaments you allow and stages promising palettes for the selected image.

  1. Under Select Filaments for Auto-Suggest, select the filaments Prisma may consider. All and None are quick starting points.
  2. Set the limits on the right.
  3. Choose the Solve mode you intend to use.
  4. Press Suggest Palettes.
  5. Compare the results and use Add to Deck on the palettes you want to solve.

The controls are:

  • Max colors — the most colored filaments in one printer load. Prisma caps this to the color slots available after reserving the white slot.
  • Extra color loads — allows suggestions that use additional groups of colored filaments. 0 keeps every color loaded for the whole print. Values above 0 create runs that require mid-print swaps.
  • Suggestions — how many alternatives to request.
  • Solve mode — Color evaluates palettes against the adjusted image’s colors. Luminance evaluates them for the Luminance workflow, where the white cap carries more of the light-and-dark structure.

The main alternatives are named Color suggested N or Luminance suggested N to preserve the mode that produced them. Each result shows Suggest dE. dE means delta E, a perceptual color-difference estimate; lower indicates a closer estimated fit to the suggestion target. It is useful for narrowing the field, not for declaring a winner. Palettes with similar scores can distribute their errors very differently, so solve the promising options and compare their predicted images.

The collapsible Palette Suggestion Settings panel contains two less-common controls:

  • Min added-color gain — how much improvement another color or load tier must provide before Prisma recommends continuing.
  • Compute all load tiers — tests every allowed tier even when the improvement falls below that threshold.

If the selected white is unavailable to the color model, suggestion cannot run. Filaments excluded from modeling are also ignored even if selected as candidates.

Cancel requests a stop at the next safe search boundary. The progress bar remains visible as Cancellation requested until the worker actually stops; any partial suggestions returned by the search are still shown.

Manual

Manual mode is for building a palette directly. Select filaments under Select Filaments for Palette; the Manual Palette panel shows the current set and whether it fits in one load. A manual palette may contain more colors than the available color slots, but that run will require swaps.

Press Add to Deck when the set is ready. Clear empties the manual palette.

Suggested Palettes and the Palette Deck

The Suggested Palettes column is a temporary staging area. Suggestions arrive there first so you can compare them without filling the app’s main deck. Suggested and deck cards use the same compact title-bar and chip layout. The separate boxed white chip is the currently selected base/cap filament; it is shown for context and is not counted among the colored palette filaments. Add to Deck promotes one. Clear asks for a second click within three seconds and empties only this staging area.

The Palette Deck in the left rail contains palettes ready to use. Click a card to make it active. The highlighted palette is the one the next solve uses. Hover over a card to see its filament names, base/cap filament, and suggestion score when available.

Use Save on a deck card to keep that palette under a name. Removing the card from the deck does not delete its saved copy.

📸 Screenshot to capture

The Save Palette dialog.

Load in the deck header opens saved palettes. Select one to return it to the deck, or delete a saved palette from that list. Clear asks for a second click within three seconds, removes every card from the persistent deck, and clears the active palette. It does not clear the separate Suggested Palettes staging area.

📸 Screenshot to capture

The Load list open, showing a few saved palettes with their color chips.

Once a palette is active, press Solve. For a first comparison, favor palettes that fit in one load. Extra colors are worthwhile only when the predicted improvement justifies the slower solve, white-fill trade-offs, and manual changes required by a swap run. See Runs with Swaps before printing one.

For the optical reason stacked filaments can produce colors that none of them makes alone, see Palette in How It Works.
