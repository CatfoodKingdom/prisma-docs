Preprocessing operators

Preprocessing operators

Properties1
tagsgenerator, preprocessing

Jul 27, 20264 min read

In one sentence: Generator ships five self-registering, default-off preprocessing operators—A1, B1, B3, C1, and C2—plus shared nozzle-scale and circular-hue helpers.

Operator modules are discovered lexically from preprocessing/operators/ and register with @register_preprocessing. Runtime execution is independently sorted by (order, fully-qualified class name). All five accept and emit srgb_f32; C1 and C2 internally visit OKLab and request F2 palette metadata.

Every class declares default_enabled=False. The current app persists choices in the Generator Workspace’s config/modules.json; a new workspace with no file falls back to those class defaults. The repository’s generator/app/modules.json is still consumed by evaluation scripts but is not the server’s live product-state path.

Parameters are persisted separately under preprocessing_params. A parameter record does not enable its operator.

A1—bilateral denoise

A1 applies one OpenCV bilateral filter globally to the solve-grid sRGB raster. Its flat-region mask is diagnostic only; it affects reported variance metrics, not where the filter runs.

ParameterDefaultRange
radius_px31–8
sigma_range0.040.005–0.25
sigma_spatial2.0 px0.5–10.0 px

The kernel diameter is 2 × radius_px + 1. Its debug map is absolute luma change.

B1—print-scale bilateral

B1 anchors the spatial sigma to physical print scale:

The pixel sigma is clamped to [0.5, 15], the odd kernel diameter is derived from its rounded value, and one to three bilateral passes run before a final [0,1] clip.

ParameterDefaultRange
feature_scale_multiplier1.00.5–2.0
sigma_range0.050.005–0.25
passes11–3

If the fine pitch is unavailable, B1 uses 0.20 mm for this conversion.

B3—TV flatten

B3 calls scikit-image’s Chambolle total-variation denoiser. A compatibility wrapper adapts to the installed max_num_iter/n_iter_max and channel_axis/multichannel signatures.

With autoscaling enabled:

The effective weight is clamped to [0.005, 0.30]; the operator writes a log warning when clamping occurs and reports the final effective weight in its metrics.

ParameterDefaultRange/choices
tv_weight0.040.005–0.40
weight_autoscaletrueboolean
channel_axisoklab_L_absrgb_rgb, oklab_L_ab, oklab_L_only
n_iter_max1002–500

oklab_L_only denoises L and reattaches the original a/b channels; oklab_L_ab denoises all three OKLab channels.

n_iter_max is an iteration cap, not a requested iteration count. A low cap can stop the Chambolle solver well before convergence; 100 remains the recommended default. The minimum is 2 because the installed implementation returns its input unchanged when capped at one iteration. Generator validates known preprocessing parameters against these descriptor bounds before a solve starts while retaining unknown module and parameter blocks for forward compatibility.

C1—achievable tonemap

C1 maps source OKLab lightness into F2’s sampled achievable black/white interval while preserving a/b. Source shadow and highlight percentiles become the outer PCHIP anchors; the midpoint target is controlled by 0.5 ** midtone_contrast. Linear tails extend beyond the source anchors, the result is clamped to the achievable interval, and strength blends the remap with original L.

ParameterDefaultRange
strength1.00–1
shadow_percentile0.50–10
highlight_percentile99.590–100
midtone_contrast1.00.5–2.0

The constructor also requires shadow percentile below highlight percentile. A collapsed F2 lightness range or coincident source anchors produces an identity result; the former is marked as a degenerate palette. Debug maps include delta_L and clamp masks.

C2—soft gamut compress

C2 converts the source to OKLab, interpolates F2’s chroma ceiling around the hue circle and along lightness, and compresses chroma above knee_start_ratio × bound with the pinned tanh soft knee. It scales a and b together, so hue is preserved and L is unchanged.

ParameterDefaultRange
knee_start_ratio0.850.50–1.00
knee_softness0.500.05–1.50

Missing metadata raises ValueError. Empty, malformed, or effectively zero ceilings produce identity with a degenerate metric. Debug maps include chroma_scale and over_bound_mask.

Shared feature scale

resolve_feature_scale_mm returns a positive explicit override when supplied; otherwise it returns twice the active nozzle diameter. Missing, non-numeric, or non-positive nozzle data falls back to 0.40 mm. This is a reproducible-feature heuristic, not the printer’s minimum line width. B1 and B3 are its live operator callers.

Circular hue interpolation

interpolate_circular_degrees sorts normalized sample hues, extends the final sample by −360° and the first by +360°, then uses linear interpolation across the seam. A single sample returns a constant; empty or misaligned sample arrays raise. C2 is its live production caller.
