Samples and geometries

Samples and geometries

Properties1
tagscalibration, webapp

Jul 28, 20269 min read

In one sentence: the Geometries tab is where you design the printable strip shapes — variable and fixed layer roles, exported as STEP/STL for the printer — and group them into bundles; the Logbook tab is where you fill a geometry with real filaments to create the samples you will later photograph and measure.

This page covers two screens and the drawers they open. A sample geometry is a strip design: which layers it has and how thick each swatch is, with the material left unspecified. A sample is that geometry filled with specific filaments — one per layer role. A bundle is a named group of related geometries printed together, with their shared filament slots mapped once so you can create many samples in a single pass. For the anatomy and math behind a geometry — the staircase, the spine, the structural fingerprint — see Sample Geometry; this page stays on what you click and why.

The Geometries tab

The table lists every sample geometry in the library, one row each, with columns Strip (a mini strip diagram), Alias, Bundle, # Layers, Used by (how many samples reference it), and Last modified. The summary above the table reads N sample geometries. The toolbar has three buttons:

  • + New Sample Geometry — opens the step builder drawer to design a new strip.
  • Manage Bundles — opens the bundle management drawer (toggles: click again to close).
  • Export Geometry Files — opens the geometry-library maintenance workflow for writing user-facing STEP/STL files into the public output folder. It starts with All Geometries selected, but you can switch to Only Geometries Used By Samples, choose STEP and/or STL, and run Missing Only or confirmed Force Export (see Managed artifacts vs. exports).

Clicking a row opens its detail drawer. The drawer header carries Export and Edit; the body shows the geometry’s Alias, ID, Bundle chips, Last Modified, a Used By sample list, and the Exported Files and Managed Artifacts sections. Each stored file path has a Copy Path button that copies the absolute path to the clipboard.

  • Edit switches the alias field into edit mode, where the header shows Save, Discard, and Delete. A geometry’s shape is immutable once created (Sample Geometry). Bundle membership is managed independently by the Bundle chips and picker in the same drawer; adding or removing a bundle takes effect immediately rather than waiting for the alias Save action. The current drawer does not expose geometry notes. Delete opens the Delete Sample Geometry confirmation; deletion is refused if any sample or bundle still references the geometry.
  • Export (drawer header) opens the geometry export dialog for that one geometry.

Building a geometry (the step builder drawer)

+ New Sample Geometry opens the New Sample Geometry drawer. Its header has two commit buttons: Create (save the geometry into the library) and Create + Export (save, then immediately open the export dialog).

You lay out the strip as a stack of layer role cards, ordered bottom to top:

  • Each card is either Variable or Fixed. Exactly one role must be Variable — its per-swatch thickness values are typed into the swatch input grid, and this is the staircase that sweeps the thickness axis. A Fixed role takes a single thickness that applies across the whole strip.
  • Drag a card by its handle to reorder the stack.
  • + Add Layer Role appends a new fixed role; the small remove control on a card deletes it.

The left side of the drawer is a live Visual Preview:

  • Top View scales the full strip footprint into the available box and reports its derived width and height.
  • Side View uses the same horizontal strip scale but exaggerates vertical thickness so the layer staircase remains legible.

The form on the right is divided into Strip Layout, Variable Layer Increment, Strip Definition, Strip Diagram Preview, Metadata, and Output. Variable Layer Increment is optional shorthand: enter a first swatch thickness and a swatch-to-swatch increment, then use Fill Values to populate the editable values in Strip Definition. The two previews continue to update when you edit those values directly.

The spine thickness starts at the tallest swatch stack plus 0.08 mm and continues auto-updating as the layer values change until you edit the spine field yourself. It must be at least as tall as the thickest stack. Roles are slots, not materials — the geometry never names a filament; that happens when you create samples.

Managed artifacts vs. exports

There are two distinct sets of files, and the distinction matters:

  • Managed artifacts are the app’s internal, canonical STEP/STL files, generated and owned by the backend and tracked against the geometry’s structural fingerprint. The drawer’s Managed Artifacts section reports how many exist.
  • Exports are user-facing copies written into Calibration/Output/Steps for you to hand to the slicer. The drawer’s Exported Files section records the latest export paths.

Both Create + Export and the row-level Export open the Export Sample Geometry dialog. It has a name field plus Export STEP, Export STLs, and Cancel. STEP produces one model with a labeled solid body per layer role; STLs produce one file per role, named so the slicer shows which body is which layer. If an export of the same name already exists in the output folder, a Replace Existing Export? dialog appears listing the conflicting paths, with Overwrite and Cancel. While either export request is active, the parent dialog stays open with its controls disabled; Escape, outside-click, and a second Export action cannot detach the UI from the request.

The toolbar’s Export Geometry Files button is different: it opens the multi-geometry maintenance workflow rather than exporting a single geometry. The workflow defaults to all geometries but also supports used-by-samples scope, output-type selection, missing-only generation, and confirmed force replacement.

Bundles (Manage Bundles drawer)

Manage Bundles opens the Manage Bundles drawer: a bundle list on the left, the selected bundle’s detail on the right.

  • Create a bundle by typing a name into the new-bundle row and clicking Create.
  • Select a bundle to edit it. Its header shows Rename (which reveals an inline field with Save / Cancel) and Delete.
  • Under Bundle Geometries, Add Geometries… adds member geometries; each member row has a remove control.
  • Under Bundle Filament Mapping, Edit Mapping opens the mapping editor, where you define the bundle’s shared filament slots and map each geometry’s layer roles onto them. A bundle must be fully mapped before it can drive bulk sample creation; if you save an incomplete mapping, a Save Incomplete Mapping dialog offers Save Anyway or Cancel. The bundle’s list entry shows a mapping-status pill.

A mapped bundle lets you assign a filament once per shared slot and spawn a sample for every member geometry in one action.

Creating samples (the Logbook tab)

On the Logbook tab, + New Samples opens the New Samples drawer. Its header has one commit button, Create. The drawer is a form on the left and a live Sample Preview strip diagram on the right.

  1. Select Geometry Source — a toggle between Single Geometry and Geometry Bundle, plus a picker for choosing the specific geometry or bundle.
  2. Selected Geometry Preview — shows the chosen strip so you can confirm it before assigning materials.
  3. Filament slots — one row per assignable role (or per shared bundle slot). Each row has a Single / Multi toggle:
    • Single assigns one filament to that role.
    • Multi (batch) picks several filaments for one role at once; the app then spawns a separate sample for each — one strip design, many filaments under test. Only one role can be in Multi mode at a time.
  4. Notes — an optional free-text note applied to every sample created in the batch.
  5. Sample Summary — a running count and record preview of what Create will produce.

Because roles are just slots, one geometry serves any number of filaments — the geometry decides the shape, the sample decides the material. Newly created samples land in the logbook with no photos yet, ready for Assigning images.

A note on editing an existing sample: changing which geometry or filaments a sample uses is a provenance change. If the sample already has extraction results, the change invalidates them — the app clears the measurements and marks any dependent filament profiles stale, because the old measurement no longer describes the new material stack.
