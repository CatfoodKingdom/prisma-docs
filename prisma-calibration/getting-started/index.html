Getting Started

Jul 27, 20265 min read

The calibration app turns 3D-printed filament swatches into the color models the generator prints from. This page walks one filament all the way through: from an empty library to a fitted model. For the reasoning behind each step see How It Works; for the details of each screen, How To Use.

What you need

  • The three things the app can’t do for you: a multi-color 3D printer, the filaments you want to characterize, and a lightbox with a camera that shoots RAW (the pipeline reads camera-JPEG appearance embedded in the RAW).
  • The app itself — see Installing and Launching. The Suite starts Calibration with Prisma Calibration.exe on Windows or Prisma Calibration on Linux; neither packaged platform requires Python, an IDE, or manual dependency installation.

It opens on a single page titled Calibration Logbook, backed by a SQLite database created automatically inside Calibration/Workspace on a blank first launch. It is a single-user tool: browser tabs share one process and one database. Background operations reserve the resources they need, so conflicting work is blocked even though unrelated job families are not governed by one global lock.

The shape of the work

A sample is one printed strip — a geometry filled with specific filaments — that you photograph and measure. You build up a library of samples, then fit models from the measurements you trust. The first run touches every stage once.

1 — Add your filaments

On the Filaments tab, use + New Filament for each filament: color name, manufacturer, material, and a hex color for the UI. Set its policy while you’re there — mark your white diffusers White-cap eligible, and leave Exclude from model fits off for anything you want the models to learn or a newly published Generator library to offer for new work. See Filaments.

2 — Choose a geometry

A geometry is the strip layout: a row of swatches with exactly one variable material role stepping through a range of thicknesses, plus any constant-thickness roles the design needs above or below it. On the Geometries tab, + New Sample Geometry opens the step builder, or reuse an existing geometry. See Geometries.

3 — Create the sample

On the Logbook tab, + New Samples fills a geometry with your filaments — one sample per filament you’re characterizing (the Multi mode spawns a batch at once). The sample now exists, waiting for photographs. See Creating New Samples.

4 — Print and photograph (outside the app)

Export the geometry’s print files with Export Geometry Files (Geometries tab), print the strip in the chosen filaments, and photograph it on the lightbox as RAW. Take one empty-lightbox RAW too — that’s the blank used for flatfield correction.

5 — Assign the photos

On Images → Assign Images, place the photos in the Calibration Inbox, use Import from Inbox, then assign each sample its strip image and a blank. For many samples at once, CSV Bulk Assignment does it from a spreadsheet. See Images.

6 — Extract the colors

On Images → Processing Queue, your sample sits under Ready to Process. Process All runs strip detection, deskew, flatfield correction, and per-swatch color extraction. If it lands in Failed or Flagged for Manual Processing, Manual Process lets you click the four corners by hand. Then Accept the result — only accepted extractions feed the models. See Processing Queue.

7 — Fit the working models

On the Modeling tab, the Overview shows your evidence and flags gaps; Fit Models replaces Calibration’s current copies of Color Model v1, Color Model v2, and The Camera Transform from the samples you’ve included. This does not change Generator. See Modeling.

8 — Publish a Generator library

When all three working models are current, press Publish Models in the top bar. Give the library a name, version, and publisher, then either:

  • Publish to Generator to install a new inactive library into the Generator in this Suite; or
  • Export Library Package to create a portable ZIP in Calibration/Output/Published Models for another Prisma installation or a release download.

Publishing is a copy across an ownership boundary. It does not move or replace Calibration’s working models, and later fitting cannot mutate the published copy. Select the new library through Model Library → Manage in Generator’s left panel when you are ready to use it.
