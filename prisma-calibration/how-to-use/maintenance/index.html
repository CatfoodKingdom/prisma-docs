Maintenance

Jul 28, 20262 min read

The top bar’s Maintenance button opens a dialog of housekeeping operations — checks, rebuilds, exports, and Fit Models. Operations appear as cards grouped by category; click one to select it, and Start Workflow appears on the right. Each card says whether it is Read-only or writes something. A grayed-out card is unavailable, with the reason shown.

📸 Screenshot to capture

The Maintenance dialog with an operation selected.

Only one maintenance job runs at a time — and none while a backup or restore is running. Start a second and the app tells you what’s already going.

The operations

  • Audit — four read-only checks (Audit Library Integrity, Audit Missing Artifacts, Audit Orphaned Artifacts, Audit Source Image Custody). They report problems — missing files, stray files, photo custody gaps — without touching anything.
  • Images — Rebuild Image Previews and Rebuild Extraction Images Only regenerate the app’s derived images if they’re missing or broken; Re-extract Sample Images re-measures samples, with review — see Re-extract Sample Images.
  • Calibration Models — Fit Models builds the color models. See Fit Models.
  • Geometry Artifacts — Regenerate STEPs/STLs rebuilds the app’s internally managed geometry files; Export Geometry Files writes user-facing print files (the same workflow opened from the Geometries toolbar).
  • System Maintenance — SQLite Integrity Check (read-only database health check) and Quarantine Orphaned Artifacts (sets aside files nothing references — not deleted, moved into Calibration’s app-managed maintenance quarantine, where you can inspect or recover them through the reported path).

Everything except Re-extract runs through the same three-step rhythm — see Standard Operations.

The Activity Log

The dialog header’s Activity Log button lists standard-operation reports — Name, Type, Status, File Name — newest first. A standard job blocked before execution, or whose worker raises before returning its report, has no row. Re-extract Sample Images instead keeps generation/apply reports with its staged candidate set, not in this list. Clear Log deletes only the Activity Log’s report files — never your samples, photos, backups, candidate sets, or data.
