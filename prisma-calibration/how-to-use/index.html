How To Use

Jul 14, 20263 min read

The calibration app measures how your filaments pass light, so the generator can reproduce their colors in a print. You photograph printed filament strips on a lightbox, the app reads the color out of each photo, and once you’ve checked the results it builds the color models the generator prints from.

The steps run in order. You set up the library — your filaments and sample geometries — once. Everything after that you repeat for each new set of strips.

The workflow

Every box is a page. The top row is the workflow, left to right: set up Filaments and Geometries once, then run Sample Logbook → Images → Modeling for each batch of strips. Maintenance and Backup / Restore live in the top bar and work from any tab.

  1. Filaments — add each filament you want to test.
  2. Geometries — design the calibration strips you will print.
  3. Sample Logbook — fill a geometry’s material roles with filaments to create samples.
  4. Images — give each sample its lightbox photos, then pull the colors out.
  5. Modeling — check the measurements, then build the color models.

Steps 1 and 2 are one-time setup. Steps 3–5 are the loop you run for every batch of strips.

One heads-up: the app’s own tab strip is arranged for day-to-day use — Logbook first, then Images, Filaments, Geometries, Modeling — so the two setup tabs sit in the middle of the strip, not at the left.

Top-bar tools

These top-bar buttons work from any tab:

  • Refresh Data — reload the app’s current data when a view looks out of date. It does not import files that are waiting in the Image Inbox; use Import from Inbox on the Images page for that.
  • Maintenance — housekeeping jobs, and the button that builds the models.
  • Restore — save a copy of your work, or bring one back.

Getting set up

  • Getting Started — installing and launching the app, and a first run end to end.
  • Tutorials — full walkthroughs from start to finish.

Good to know

Only one heavy job runs at a time — extracting colors, fitting models, or making a backup. Start a second and the app asks you to wait. That’s expected, not an error.

Nothing you measure reaches a print until you run Fit Models from the Modeling tab. To understand what a measurement is or how the models work, see How It Works.
