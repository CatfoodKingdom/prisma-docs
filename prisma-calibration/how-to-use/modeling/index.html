Modeling

Jul 15, 20264 min read

Everything upstream produced measurements; this tab is where you decide which measurements the color models learn from, then fit Calibration’s current models. A separate publication step turns an exact current generation into a stable Generator library.

📸 Screenshot to capture

The Modeling tab — the model status list, the Fit Models button, and the three subtabs.

The header — model status and Fit Models

The header shows the status of each current working model — Color Model v1, Color Model v2, and Camera Transform — as:

  • Current — Calibration has a registered fit that no tracked contributor/control mutation has marked stale. This status alone is not a live hash check of every artifact, and newly accepted evidence that was not a contributor does not retroactively stale an existing fit; Publish Models readiness performs the stricter artifact validation before copying a library.
  • Stale — evidence or a fit control that contributed to the retained model has changed since it was built. A Fit Models needed banner appears. This is normal; it just means “build again.” Newly accepted evidence does not by itself rewrite the existing model.
  • Missing — never built yet.

Fit Models fits Color Model v1 and Color Model v2 from the currently included evidence. It also fits the Camera Transform when needed, or whenever Force Camera Transform is selected. See Fit Models. What the models are is covered in Color Model v1, Color Model v2, and The Camera Transform.

Two ways to keep data out

  • Here (and on the Sample Record): exclude one sample or one swatch from the next fit. These controls are reversible and suit one suspect strip or swatch.
  • On Filaments: Exclude from model fits removes a filament wholesale until the setting is cleared. Use it for a retired or mis-measured filament. A Generator library published afterward records that filament as unavailable for generation; previously published immutable libraries do not change.

The subtabs

  • Overview — is the evidence healthy? Your pre-build checklist.
  • Samples — include or exclude each sample; compare measurements to the models.
  • Filaments — does each filament have enough data to be modeled well?

The usual loop: read the Overview, spot-check and curate Samples, check coverage on Filaments, then Fit Models. A stale or missing model is a reason to fit; it is not something you must clear first.

Publish the exact current generation

Fit Models and Publish Models are deliberately different operations:

  • Fitting replaces Calibration’s internal working models. Those models remain under Calibration’s exclusive ownership and may become stale or be rebuilt as evidence changes.
  • Publishing creates a new immutable Generator library from the exact current Color Model v1, Color Model v2, Camera Transform, and public filament catalog. It never modifies a previously published copy.

Press Publish Models in the app’s top bar. The dialog checks all four required components and blocks publication if a model is missing, stale, invalid, changed on disk, or inconsistent with the others. When it reports Ready to publish, enter a required Library name, Version, and Publisher or author; description and release notes are optional.

Choose one action:

  • Publish to Generator validates and installs a new library in this Suite’s Generator\Model Libraries. It is installed inactive so the running Generator cannot change underneath an open session. Open Model Library → Manage in Generator’s left panel and choose Activate and Restart Prisma when ready.
  • Export Library Package writes a validated ZIP under Calibration\Output\Published Models. Send that unchanged ZIP to another Generator, or distribute it as a model-library update; the receiving user opens Model Library → Manage in Generator’s left panel and chooses Install Library….

Both actions build the same payload. The published library contains only the public filament catalog and runtime artifacts for the three model families—not Calibration’s SQLite database, sample records, raw photographs, per-sample predictions, notes, or other working evidence.
